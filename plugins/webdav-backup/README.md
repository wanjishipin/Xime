# WebDAV 云备份（Xime 插件）

通过 WebDAV 将曦码输入法的数据备份到云端。备份内容（由宿主打包）：

- rime/ 目录：输入方案、词典、用户配置、**自造词**（userdb / t9_digit.userdb）
- 设置项、插件配置、插件注册表（plugins.xml）
- 插件包（完整备份模式）

支持查看远端备份列表、按快照恢复、删除远端备份。

## 配置说明

| 字段 | 说明 |
|---|---|
| 服务器地址 | WebDAV 根地址，如坚果云 `https://dav.jianguoyun.com/dav/` |
| 账号 | WebDAV 账号 |
| 密码 / 应用密码 | 坚果云请到网页端「安全选项」生成**应用密码**（不要用登录密码） |
| 备份目录 | 远端目录，默认 `/xime_backup`，不存在时自动创建 |

## 使用

设置 → 同步与备份 → 云备份 → 启用「WebDAV 云备份」→ 填写配置 → 测试连接 → 立即备份。

恢复后需重启应用生效。

## 隐私与安全

- 备份包只在宿主与本插件之间传递，本插件只做上传/下载，不解析备份内容。
- 密码由宿主加密存储（host.config）。
- 服务器域名需经宿主联网授权（首次保存配置时自动请求）。
